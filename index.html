About Marin WayMaker

        
Marin WayMaker helps you build step-by-step decision guides and publish them as interactive web forms.

        
What you can do

        
    
          
  • Build a guide with questions, answers, information, and results.
    • 
          
  • Preview the end-user experience before publishing.
    • 
          
  • Download a standalone web form anyone can use.
    • 
          
  • Save an editable copy and reopen it later.

How answers work

        
For choice questions, each answer leads to a specific next step. For number and text questions, rules are checked from top to bottom and the first matching rule determines the next step. An "otherwise" rule acts as a catch-all fallback.
